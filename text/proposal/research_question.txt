RESEARCH QUESTION FRAMING
=========================
Last updated: 2026-01-29 (v4 - Revised experimental design)

================================================================================
CORE QUESTION
================================================================================
"Do semantic priors enable qualitatively different emergent social structures
than pure optimization, or do material incentives dominate regardless of
reasoning architecture?"

Alternative phrasing:
- "How do different reasoning architectures shape emergent social structures
   in repeated multi-agent interaction?"

================================================================================
KEY INSIGHT
================================================================================
Axelrod (1984) showed self-optimizing agents CAN achieve cooperation through
repeated interaction. But this cooperation is MECHANISTIC: agents discover
stable equilibria through trial-and-error without "understanding" cooperation.

QUESTION: Does semantic reasoning (LLMs) enable QUALITATIVELY DIFFERENT
social structures - more stable coalitions, faster trust-building, emergent
norms - or do material incentives dominate regardless of how agents reason?

================================================================================
EXPERIMENTAL DESIGN (REVISED)
================================================================================

| Condition       | Architecture | Information      | Purpose                    |
|-----------------|--------------|------------------|----------------------------|
| RL (LSTM)       | Optimization | Minimal state    | Baseline: optimization     |
| LLM-Comparison  | Semantic     | Same as RL       | Test: architecture effect  |
| LLM-Control     | Semantic     | Minimal + varied | Robustness: prompt effects |

KEY DESIGN CHOICES:

1. RL WITH MEMORY (LSTM)
   - Addresses Debraj's concern: LLMs have episodic memory, standard RL is
     Markovian. LSTM gives RL comparable memory capacity.
   - If LLMs form coalitions and RL doesn't, it's not just memory confound.

2. LLM-COMPARISON: SEMANTICALLY STRIPPED
   - Receives SAME minimal information as RL agent.
   - No social framing, no identity priming, no norm language.
   - Pure architectural comparison: does semantic reasoning ITSELF matter?

3. LLM-CONTROL: PROMPT VARIATIONS
   - Same minimal information, but with variations in prompt wording.
   - Tests robustness: are LLM-Comparison results stable or prompt-dependent?
   - Addresses "is this just prompt engineering?" concern.

================================================================================
WHAT THIS DESIGN ISOLATES
================================================================================

COMPARISON 1: RL (LSTM) vs LLM-Comparison
- Same goal, same information, same memory capacity
- Different: HOW they process information (optimization vs semantic reasoning)
- If they diverge: semantic reasoning architecture produces different structures

COMPARISON 2: LLM-Comparison vs LLM-Control variations
- Same architecture, same information format
- Different: prompt wording variations
- If stable: results are robust, not prompt artifacts

================================================================================
POSSIBLE OUTCOMES
================================================================================

1. RL ≈ LLM-Comparison
   → Architecture doesn't matter. Material incentives dominate.
   → Semantic reasoning adds nothing to emergent structures.

2. RL ≠ LLM-Comparison, LLM-Control stable
   → Architecture matters. Semantic reasoning enables different structures.
   → Results are robust across prompt variations.

3. RL ≠ LLM-Comparison, LLM-Control unstable
   → Differences are prompt-dependent, not architectural.
   → Need more controlled prompting methodology.

All three outcomes are publishable findings.

================================================================================
GAME DESIGN
================================================================================
Minimal game enabling rich emergent structures:

| Action   | Target | Effect                        | Enables...              |
|----------|--------|-------------------------------|-------------------------|
| Invest   | Self   | Resource growth               | Individual accumulation |
| Invest   | Other  | Transfer resources            | Trust signaling         |
| Arm      | Self   | Military capability           | Threat/defense          |
| Arm      | Other  | Alliance signal               | Coalition building      |
| Attack   | Other  | Resource appropriation        | Conflict, hierarchy     |

KEY: Agents optimize ABSOLUTE resources (not relative position).
- Cooperation naturally attractive (positive-sum possible)
- Tests whether agents DISCOVER cooperation
- Divergence is about reasoning, not reward structure

================================================================================
METRICS (EMERGENT STRUCTURES)
================================================================================

COALITION DYNAMICS:
- Number/size of coalitions
- Coalition stability (duration)
- Formation speed

COOPERATION PATTERNS:
- Reciprocity rate
- Trust persistence after conflict
- Network density

HIERARCHY:
- Gini coefficient over time
- Hub emergence (centrality)
- Power concentration trajectory

CONFLICT:
- Attack frequency over time
- Betrayal rate (attack former ally)
- Escalation patterns

================================================================================
THEORETICAL GROUNDING
================================================================================
This extends Axelrod (1984) into the semantic reasoning era:

AXELROD: Can self-interested optimizers cooperate?
ANSWER: Yes, mechanistically, through trial-and-error.

THIS THESIS: Do semantic reasoners cooperate DIFFERENTLY?
- Faster trust-building?
- More stable coalitions?
- Emergent norms?

If YES: Semantic priors enable richer coordination.
If NO: Material incentives dominate regardless of reasoning.

================================================================================
VALIDATION APPROACH (per Larooij & Törnberg 2025)
================================================================================
NOT validating:
- Micro-level realism of individual agents
- Whether agents "accurately" model real actors

VALIDATING:
- Do different architectures produce different MACRO structures?
- Are differences robust across parameter variations?
- Can we identify WHAT about semantic reasoning causes differences?
  (Analyze LLM reasoning traces for norm/identity/trust references)
