# 5. Expected Contribution

## Empirical Contributions

### 1. Direct Test of Structural Realism
First computational validation of Waltz's core claim: do balance-of-power dynamics emerge from anarchy alone, without shared norms or institutions?

**Novel element**: Uses modern multi-agent RL to test 1979 theory that predates computational methods

### 2. "Reward is Enough" in Social Contexts
Tests Silver et al.'s hypothesis in a domain (coalition formation, power politics) typically assumed to require high-level reasoning

**Novel element**: Direct comparison of semantic vs non-semantic agents under identical incentives

### 3. Isolation of Cognitive Architecture Effects
Most multi-agent work uses homogeneous agents. This research systematically varies cognitive architecture while holding environment constant.

**Novel element**: Same objective function, different cognitive tools—isolates role of semantic understanding

## Methodological Contributions

### 1. Implicit vs Explicit Cooperation
Existing models have explicit coordination mechanisms ("form coalition" buttons). "The Lattice" uses only implicit power backing.

**Advantage**: Tests whether cooperation emerges from structural incentives alone, not from pre-designed coordination tools

### 2. Minimal Environment Design
No communication channels, no shared history, no reputation systems—only utilities, bonds, and conflict.

**Advantage**: If stable structures emerge here, they're truly minimal; adding complexity can only strengthen the result

### 3. Clean Semantic Test
LLM prompts vary *only* in semantic framing (semantic vs control), not objective or information.

**Advantage**: Isolates role of concepts like "loyalty" while keeping utility maximization constant

## Theoretical Contributions

### 1. Structure-Agency Debate
Provides empirical evidence for either:
- **Materialism**: If all agents converge → material constraints determine order
- **Constructivism**: If semantic agents diverge → ideas causally shape outcomes

**Impact**: Moves longstanding debate from armchair philosophy to testable computational experiments

### 2. Emergent vs Designed Institutions
If stable hierarchies emerge without explicit design → supports evolutionary accounts of institutions

If semantic agents are necessary → supports rationalist accounts requiring shared understanding

### 3. Predictive Power
If agent type predicts structural outcome → cognitive architecture matters for political forecasting

If friction parameter dominates → environmental constraints are better predictors than actor characteristics

## Interdisciplinary Impact

### Political Science
- Validates (or refutes) core assumptions of realist IR theory
- Provides computational tools for theory testing

### AI Research
- Tests generality of "pure optimization" paradigm
- Clarifies when semantic understanding adds functional value

### Complex Systems
- Demonstrates emergence of macro-level order from micro-level incentives
- Provides benchmark for multi-agent cooperation research

## Practical Implications

### Policy Design
If material constraints dominate → focus on changing incentive structures (conflict costs, resource distribution)

If semantic understanding matters → focus on building shared norms and communication

### AI Safety
If LLM agents behave fundamentally differently → need separate governance frameworks for semantic vs non-semantic AI in multi-agent settings

## What This Research Does NOT Claim

- This is **not** about real-world political forecasting (too simplified)
- This is **not** about optimal agent design (about understanding mechanisms)
- This is **not** about superintelligent AI alignment (about emergent coordination)

**Scope**: Fundamental research on the *minimal conditions* for emergent social order
