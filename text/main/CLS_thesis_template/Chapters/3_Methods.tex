Our coordination game is defined as a tuple $G = \langle \mathcal{N}, \mathcal{S}, \mathcal{A}, O, T, u \rangle$:

\begin{itemize}
    \item $\mathcal{N} = \{1, \ldots, n\}$: a set of $n = 30$ agents.
    \item $\mathcal{S} = (\mathbf{R}(t), \mathbf{B}(t), G(t))$: the state at round $t$, consisting of resource vectors $\mathbf{R}(t) \in \mathbb{R}_{+}^{n}$, arm bonus vectors $\mathbf{B}(t) \in \mathbb{R}_{+}^{n}$, and a social network $G(t) = (V, E(t))$ where $V = \mathcal{N}$ and the edge set $E(t)$ evolves through rewiring (Section~\ref{sec:topology}).
    \item $\mathcal{A} = \{\texttt{do\_nothing},\; \texttt{invest\_other}(j),\; \texttt{arm\_self},\; \texttt{arm\_other}(j),\; \texttt{attack}(j)\}$: the action set, where $j \in \mathcal{N}_i(t)$ denotes a network neighbour of agent $i$. Agents may only target direct connections.
    \item $O_i(t) \subseteq \mathcal{S}$: the observation function. Agent $i$ observes its own resources and arm bonus, but \textit{not} the resources of neighbours. Agent $i$ observes the recent actions and combat outcomes involving its network neighbourhood $\mathcal{N}_i(t)$, accumulated through persistent local memory (Section~\ref{sec:memory}).
    \item $T: \mathcal{S} \times \mathcal{A}^n \rightarrow \mathcal{S}$: the transition function. All agents act simultaneously; actions are resolved in a single step. All costs and returns are percentages of the acting agent's current resources.
    \item $u_i(t) = R_i(t+1) - R_i(t)$: the payoff for agent $i$, defined as the change in resources. Agents are instructed to maximise their absolute resource count.
\end{itemize}

Our game is designed to produce rich emergent dynamics by utilizing minimally sufficient components, following the \textit{Generative Sufficiency} precedent set by Epstein \cite{?}. The step away from classical games researched thoroughly in game theory, such as the Prisoners Dilemma or Stag Hunt, is motivated by the absence of emergent behaviour possible using large-language model driven agent architectures. The six actions prove to be rich enough for dynamics such as coalition-forming, arms races, bandwagoning, mobbing, hierachies and signalling, where classical games simply wouldn't suffice without modifications. Our game can be seen as an extension to the classical stag hunt, though staying minimal to causually analyse the outcomes.

All costs and returns are a percentage of the actor's resources $R_i(t)$. This design choice rests on assuring scale invariance, meaning both rich and poor agents face similar dilemmas disregarding their wealth and aligns with canonical ABM practice \cite{EpsteinAxtell1996}.
There are two \textbf{cooperative} actions, \texttt{invest\_other} and \texttt{invest\_self}, which grow the total economy. However, investing in another agent costs the actor $c_{\text{inv}}\%$ of their resources, making the action only valuable for their own wealth if they expect reciprocity in the following rounds. Investing in oneself removes that uncertainty, but the net percentage gain ($g_{\text{self}}$) is smaller and the actor is limited by their own wealth. Both actions simultaneously exhibit a signalling function: investing in others can be seen as goodwill, trust and an invitation for cooperation, while investing in oneself can be seen as asocial, though practical. Additionally, the cost of investing in another agent ($c_{\text{inv}}$) is smaller than the return for the target ($r_{\text{inv}}$), creating a social dilemma: individually investing is costly, but collectively the action is net-positive.

Three \textbf{military} actions introduce additional dynamics: \texttt{arm\_self} creates extra combat power ($B_i$) for a limited time and can be used both offensively and defensively. Seeing a neighbor arm themselves poses a threat either way, as their intentions are not known to the agent. Actors can also decide to \texttt{arm\_other}, increasing the combat power of a neighbor. Arming other agents can signal extreme trust and enables stronger agents to substantially strengthen a weaker neighbor for a limited time. The combat bonuses are subject to a decay ($\delta$) to prevent permanent escalation. Keeping high combat bonuses requires repeated arming. %baliga 2004 cite, maar nog niet gelezen!

The \texttt{attack} action is a direct way to transfer wealth between agents. Both the actor and target pay conflict cost ($c_{\text{war}}$) after which their chances of winning the conflict is decided by the ratio of their resources + combat bonus. The winner takes $\alpha\%$ of the losers resources, disregarding who was the initiator of the attack.

\subsection{Communication Scope}
%   DESIGN DECISION (Mar 2): Communication IV = scope of cheap talk channel.
%   No enforcement/contracts — that's a different mechanism entirely (future work).
%   Instead, manipulate WHO can hear your message: nobody, one agent, or all neighbours.
%
%   Four levels on a single dimension — communication SCOPE:
%   (1) No communication (baseline — Hobbesian state of nature)
%       Agents choose actions based only on observation and memory.
%       Pure "state of nature" — no coordination channel exists.
%   (2) Direct message only (private cheap talk)
%       Pre-action phase: agent sends 1 message to 1 neighbour. PRIVATE —
%       only the recipient sees it. Enables bilateral deals, secret coalitions,
%       conspiracies. But no public coordination.
%   (3) Broadcast only (public cheap talk)
%       Pre-action phase: agent sends 1 message to ALL neighbours. PUBLIC —
%       everyone in your neighbourhood sees it (including potential targets).
%       Enables coordination, public commitments, norm enforcement, shaming.
%       But no secrecy — your intentions are visible.
%   (4) Choice (agent selects DM or broadcast each round)
%       Agent decides whether to send private or public message.
%       This is the "full capability" condition — tests not just the EFFECT
%       of communication but also the PREFERENCE. Do agents choose conspiracy
%       (DM) or coordination (broadcast)? Does this vary by reasoning level?
%       L3 might strategically use DM for secret deals and broadcast for
%       public threats or norm enforcement.
%
%   The key contrasts:
%   - DM vs broadcast: HIDDEN coordination (conspiracies) vs PUBLIC coordination (norms)
%   - Choice condition: reveals agent PREFERENCES for private vs public communication
%     Channel choice itself becomes a dependent variable — proportion DM vs broadcast
%     by reasoning level, round, network position.
%   This is a clean manipulation of the message space without introducing
%   a fundamentally different mechanism (enforcement).
%
%   All messages are cheap talk (Crawford & Sobel, 1982): non-binding,
%   costless, potentially deceptive. The question is whether the SCOPE of
%   the channel changes the informativeness of communication.
%
%   Implementation (pre-action messaging phase):
%   - No-comm: skip messaging phase entirely
%   - DM only: LLM outputs {"message": "...", "to": "Agent_X"} before action choice.
%     Message appended to recipient's observation next round.
%   - Broadcast only: LLM outputs {"message": "...", "to": "all"} before action choice.
%     Message appended to ALL neighbours' observations next round.
%   - Choice: LLM outputs {"message": "...", "to": "Agent_X" OR "all"}.
%     Agent decides channel per round. Channel choice logged as DV.
%   Messages stored in memory system alongside action observations.
%
%   Interaction with network rewiring (w):
%   - Static network (w=0): broadcast audience is fixed — stable public sphere
%   - Dynamic network (w=1): broadcast audience changes each round — fluid public
%   - DM on dynamic networks: bilateral deals are fragile (partner may rewire away)
%
%   Theoretical grounding:
%   - Crawford & Sobel (1982): strategic information transmission (cheap talk)
%   - Farrell & Rabin (1996): when is cheap talk credible?
%   - Sally (1995): meta-analysis — communication boosts cooperation ~40% in
%     social dilemma experiments. But mechanism unclear (commitment vs coordination)
%   - Hurwicz (1960): message space as mechanism design input
%   - Baliga & Sjöström (2004): arms races with/without communication
%   - Dafoe et al. (2020): communication as key to cooperative AI
%
%   Hobbes mapping (strong): "lack of common power" — without communication,
%   agents cannot coordinate to escape the Hobbesian trap. Cheap talk tests
%   whether WORDS alone (without enforcement) can create order.
%   DM vs broadcast tests whether order requires PUBLIC commitment or
%   whether private bilateral deals suffice.
%
%   Future work: binding contracts with enforcement (Hobbes's Leviathan,
%   Conitzer 2024 program equilibria) would test whether cheap talk's limits
%   can be overcome by adding commitment devices. But this requires a
%   fundamentally different engine mechanism — out of scope for this thesis.
%
%   Gap: No LLM multi-agent paper systematically varies communication SCOPE
%   as IV. Existing work (WarAgent, negotiation studies) includes communication
%   but doesn't manipulate the channel structure experimentally.
%
%   STATUS: Not yet implemented (Phase 2d). Design finalized.
