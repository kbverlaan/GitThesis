\subsection{Agent Memory}
%   Local observation memory (decision Mar 1):
%   - Agents accumulate observations from their own perspective only
%   - No god-view: agents don't know what happened outside their radius
%   - Memory window: sliding window of last 10 rounds (configurable)
%   - Per-neighbour: tracks last observed action, resources, round
%   - Stale entries: neighbours that moved out of range show "last seen round X"
%   - Memory OFF = no history, only current state (no reciprocity possible)
%   - Memory ON = default. Without memory, do_nothing is Nash equilibrium
%     (invest_other costs you 10%, returns go to target, not you)
%
%   Connect to theory:
%   - Park et al. (2023): Generative Agents memory stream (ours is simplified)
%   - No game-theory LLM paper has systematic memory architecture manipulation
%     → potential methodological contribution
%
%   Key difference from standard ABM: memory is IN THE PROMPT, not in hidden
%   state. What the agent "knows" is exactly what's in its context window.
%   This is both a feature (transparent) and a limitation (context length bound).

% TODO: 3.3.1 — IV1: Reasoning Depth (L0-L3)
\subsection{Reasoning Depth}
%   Operationalized as prompt-level manipulation of deliberation depth:
%   - L0: "State your choice briefly. Do not deliberate."
%     → Heuristic/reactive, minimal computation (K-level 0)
%   - L1: "Compute the expected resource change for each action, then choose
%          the highest payoff. Do not predict what neighbors will do."
%     → Best-response, no opponent modeling (K-level 1)
%   - L2: "Predict each neighbor's most likely action based on their recent
%          behavior, then choose your best response."
%     → Opponent modeling, one level of recursion (K-level 2)
%   - L3: "Your neighbors observe your recent actions and predict what you will
%          do next. Predict their response to that prediction, then choose your
%          best action."
%     → Recursive reasoning, two levels of recursion (K-level 3)
%
%   Theoretical grounding:
%   - Cognitive hierarchy theory: Camerer, Ho & Chong (2004, QJE)
%   - K-Level Reasoning in LLMs: Zhang et al. (2024, NAACL)
%   - Kuusela & Roy (2024, AAMAS): level-0/1/2 in 2-agent RL → Hobbesian Trap
%   - Prompt as computational depth manipulation: Pfau et al. (2024)
%
%   Why prompt manipulation, not different models?
%   - Single model eliminates architecture confounds
%   - Same weights, same training data — only instruction changes
%   - Cleaner causal inference than comparing models differing on 100 dims
%
%   Faithfulness caveat (MUST include):
%   - Reasoning traces are behavioral data, not mechanistic explanations
%   - Cite: Turpin (2023), Lanham (2023), Chen (2025)
%   - We manipulate prompt-elicited deliberation, not "true" reasoning depth
%   - Thinking token distributions: L1 mean ~4800, L3 mean ~5600 (only 17% diff)
%     → model thinks deeply regardless of prompt level

% TODO: 3.3.2 — IV2: Information Structure
\subsection{Information Structure}
%   Two sub-manipulations (MD type space):
%   (a) Visibility: interaction_radius controls observation range
%       Radius 1 (local, ~4 neighbours) → radius 2 (~12) → global (all visible)
%   (b) Memory: persistent local observations vs stateless
%       See §3.2.3 for memory architecture details
%
%   Theoretical grounding:
%   - Harsanyi (1967-68): incomplete information games, type uncertainty
%   - Hobbes's "diffidence" (narrative frame, with caveat — see chapter header)
%   - Information asymmetry creates strategic uncertainty → defensive behaviour
%
%   NOTE: hide_resources (agents see only own resources) was considered but

% TODO: 3.3.3 — IV3: Communication and Enforcement
\subsection{Communication and Enforcement}
%   Three conditions (MD message space):
%   (1) No communication (baseline — Hobbesian state of nature)
%       Agents choose actions based only on observation, no messaging
%   (2) Cheap talk: pre-round messaging, not binding
%       Agents can send messages to neighbors before choosing actions
%       Messages have no enforcement — cheap talk (Crawford & Sobel, 1982)
%   (3) Contracts with enforcement: binding agreements + punishment for defection
%       Agents can propose/accept agreements; violation = automatic penalty
%       Implements Hobbes's Leviathan: external enforcement enables cooperation
%
%   Theoretical grounding:
%   - Crawford & Sobel (1982): strategic information transmission
%   - Hurwicz (1960): message space as mechanism design input
%   - Baliga & Sjöström (2004): arms races with/without communication
%   - Schelling (1960): commitment as strategic tool
%   - Dafoe et al. (2020): commitment as key to cooperative AI
%

%   depends on Phase 2c results and compute budget.
