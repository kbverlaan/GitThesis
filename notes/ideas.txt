## Directly Relevant to Current Design

CORE HYPOTHESIS — CAMERER vs KUUSELA (Mar 2, from reading Camerer 2004):
  Two competing predictions for what deeper K-level reasoning does:
  - Camerer (2004): more K-levels → convergence toward Nash equilibrium.
    The recursive structure "corrects" — higher levels compensate for
    lower levels' errors. System converges.
  - Kuusela & Roy (2024): more K-levels → AWAY from peaceful equilibrium.
    Under incomplete info + preventive advantage, deeper reasoning
    amplifies fear → pre-emptive attacks. The Hobbesian Trap.
  KEY INSIGHT: which prediction holds DEPENDS ON GAME PARAMETERS.
    High conflict_cost + low attack_take → Nash is cooperative → Camerer
    Low conflict_cost + high attack_take → attack is profitable → Kuusela
  This maps directly to our OAT sweep: the parameter space contains a
  BOUNDARY between Camerer-regime and Kuusela-regime. Finding that
  boundary is potentially the strongest result of the thesis.
  Hypothesis: "Reasoning depth interacts with game structure to determine
  whether the system converges toward cooperative equilibrium (Camerer)
  or the Hobbesian Trap (Kuusela)."

THINKING BUDGET AS CONTINUOUS VARIABLE:
  Qwen3.5 supports thinking_budget parameter natively. Could replace discrete
  L0-L3 with continuous reasoning depth (0 / 512 / 2048 / 8192 tokens).
  Same weights, same prompt, only depth changes — clean manipulation.
  Pro: finer-grained, no prompt confound. Con: less interpretable, harder to
  connect to K-level theory (Zhang et al.).

MIXED REASONING LEVELS (from Kuusela & Roy comparison):
  Agents with different reasoning depths in the same game (e.g., 15 L0 + 15 L2).
  Do deeper reasoners dominate or get exploited by naïve cooperators?
  Tests ecological validity — in reality not everyone reasons equally deep.

STREAK ANALYSIS (from Kuusela & Roy):
  Geometric distributions of peace/attack streaks per reasoning level.
  Does deeper reasoning break peace streaks faster? Cheap to add to analysis.

SURPASS SCENARIO:
  Start 1 agent with 2x resources, measure when others attack. Does reasoning
  depth lower the threshold for preventive conflict?

NETWORK REWIRING INSTEAD OF GRID MOVEMENT (Mar 2):
  Replace fixed spatial grid with dynamic social network. Instead of agents
  moving on a grid, agents periodically rewire connections: drop low-utility
  neighbours, add new ones (random or preferential attachment).
  - Solves Debraj's "random movement isn't representable" feedback (Jan 30)
  - Movement becomes part of base game, not an IV — keeps IVs independent
  - Rewiring rules (e.g., drop worst neighbour every N rounds) are engine-level,
    no LLM decision needed
  - Enables richer network metrics (clustering evolution, community detection,
    degree distribution) — already have code for this in metrics.py
  - Architecturally: replaces grid + interaction_radius with adjacency graph.
    Significant refactor of engine.py, main.py, prompts.
  - Literature: Santos et al. (2006) "Cooperation prevails when individuals
    adjust their social ties", Perc et al. (2017). Also Epstein & Axtell (1996)
    for spatial ABM comparison.
  - Options for rewire rule: utility-based (drop lowest-return neighbour),
    threat-based (drop most-armed neighbour), random with bias, or Schelling-
    style threshold (flee if >k% hostile neighbours).
  - DECISION: Discuss with Debraj on Mar 14 before implementing. Risk: big
    refactor with 1723 SBU remaining.

## Possible PhD Directions

ENDOGENOUS MECHANISM DESIGN — AGENTS CREATE THE RULES (Mar 2):
  Instead of fixed game rules, let agents propose/modify rules themselves.
  Options:
  - Agents vote on rule changes each N rounds (constitutional AI)
  - Concordia-style Game Master (GM) that adjudicates emergent rules
  - Agents propose institutions (enforcement, taxation, trade agreements)
    and a GM LLM evaluates feasibility/consistency
  Current thesis: fixed rules, manipulate cognition/info/enforcement as IVs.
  This direction: rules themselves are endogenous → everything is emergent.
  Fundamentally different research question: not "how does X shape order"
  but "what institutions do agents create, and do they converge on efficient
  mechanisms?" — endogenous mechanism design.
  Literature: Concordia (DeepMind, 2023), constitutional AI (Anthropic),
  Ostrom (1990) on self-governance, Maskin (1999) implementation theory.
  Too big for thesis — kills causal inference (no controlled IVs).
  Strong PhD venue: "Emergent Institutions in LLM Societies."

## Possible Paper Directions

REASONING vs EMERGENCE — CAUSAL LINK:
  Is individual reasoning causally linked to emergent structure, or epiphenomenal?
  Unique to LLMs: RL Q-values ARE behavior, but LLM traces CLAIM to explain it.
  Preliminary finding (Gemma 2, Feb 18): reasoning language differs systematically
  between high/low Gini runs even with identical action distributions. Subtle
  reasoning differences compound over 50 rounds → Matthew Effect at reasoning level.

SEMANTIC ABLATION (Dubey et al. 2018):
  Masked ("Action A"), Reversed ("attack"→"cooperate"), Minimal (numbers only).
  Tests how much emergent structure depends on linguistic priors vs game mechanics.
  Consistent with Arch Exp 1+2 finding (η²=0.90 for framing).
